# MD PeeK App Store Pages

Static pages for App Store Connect:

- `index.html`: simple marketing page
- `privacy.html`: Privacy Policy URL
- `support.html`: Support URL

Before publishing, replace `YOUR_SUPPORT_EMAIL` in `privacy.html` and `support.html`.

Recommended App Store Connect URLs after GitHub Pages is enabled:

```text
Marketing URL: https://YOUR_GITHUB_USERNAME.github.io/md-peek/
Privacy Policy URL: https://YOUR_GITHUB_USERNAME.github.io/md-peek/privacy.html
Support URL: https://YOUR_GITHUB_USERNAME.github.io/md-peek/support.html
```
